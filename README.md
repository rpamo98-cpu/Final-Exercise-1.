# Student Service Request SLA Monitoring

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Retrain model
```bash
python train_model.py
```

## Streamlit Cloud
Upload the complete project folder to GitHub. Select the repository, branch, and `app.py` as the main file.
